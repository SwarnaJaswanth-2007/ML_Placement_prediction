Placement Prediction & Salary Estimation ML Studio

An end-to-end Machine Learning web application covering data ingestion, preprocessing, EDA, Simple Linear Regression, Multilinear Regression, and advanced Boosting Techniques (AdaBoost, Gradient Boosting, XGBoost, LightGBM).

🚀 Quick Pipeline Access

📂

Data Ingestion

Inspect raw dataset of 50,000 students, view column data types, missing value statistics, and duplicate checks.
⚙️

Data Preprocessing

Median imputation for missing assessment scores, categorical encoding, and Z-score standardization.
📊

Exploratory Analysis (EDA)

Univariate distributions, box plots by college tier, placement rates, and correlation heatmaps.
📈

Simple Linear Regression

Univariate regression ($y = mx + c$) on any academic or test feature with 2D best-fit line & confidence interval band.
📐

Multilinear Regression

OLS, Ridge (L2), Lasso (L1), and ElasticNet with VIF multicollinearity detection, coefficient rankings, and residual analysis.
⚡

Boosting Studio

Train & tune AdaBoost, Gradient Boosting, XGBoost, and LightGBM with stagewise loss curves.
🏆

Model Benchmark & Leaderboard

Head-to-head comparison of all 8 models on identical splits for $R^2$, RMSE, MAE, latency, and consensus feature importance.
🎯

Interactive Salary Predictor

Real-time salary & placement simulation with preset candidate profiles and multi-model consensus prediction.
